三、FET 方法 → 代码映射（1:1）

FET 免费版概念代码实现
调性锚定（I–IV–V–I）cadenceChords(T)：按大调/小调生成 4 个三和弦并依次播放
单音音级识别目标音 = T + targetOffset；用户点 CHROMA[idx] 按钮；answer() 比较 idx === targetOffset
大调 / 小调 模块SCALES.major/minor.offsets 决定自然音级集合与和弦质量
半音 Chromatics 模块chromSwitch 开启后答案集合扩为 12 个半音（含 Di/Me/Fi/Se/Te 等变化唱名）
转调不变性训练每轮主音 T = 55 + rand(13)（G3–G4）随机，强制耳朵适应不同调
标签（唱名/级数/音名）labelSeg 切换 labelFor() 输出（可动 do 唱名 / 级数 / 绝对音名）
逐音反馈与弱项暴露正确/错误高亮 + renderStats() 画逐级数正确率条

四、音色合成链路

  • SF2 文件：soundfonts/GeneralUserGS.sf2（31MB，RIFF/sfbk，S. Christian Collins，宽松许可可再分发）。
  • WASM 内核：js/externals/libfluidsynth-2.4.6.js —— FluidSynth 的 Emscripten 编译版，wasm 已 base64 内嵌（330KB），无需额外下载。
  • JS 封装：js/dist/js-synthesizer.js —— 暴露 JSSynth 全局，提供 Synthesizer、waitForReady()、loadSFont()、midiNoteOn/Off、midiProgramChange。
  • 发声：synth.init(sampleRate) → createAudioNode(ctx, 8192) → 连 ctx.destination；midiProgramChange(0, p) 选乐器；midiNoteOn(0, midi, vel) / midiNoteOff 触发与停止。
为什么不用 Web Audio 振荡器硬合成？FET 的价值在于“真实乐器音色下的功能听辨”。用真实 SF2 采样（钢琴）更贴近原版体验，也呼应上一轮“SF2 音色”的调研结论。若日后要切换吉他/弦乐，仅需改 INSTRUMENTS 的 GM program 号。

六、可扩展性（付费版功能如何叠加）

当前实现的是 免费版 路径。FET 付费版（Plus） 的功能可在现有架构上增量叠加，无需重做核心：

付费功能叠加方式

七、运行方式

# 在项目目录启动本地服务器（浏览器禁止 file:// 读取本地 SF2）
cd ~/Desktop/fet-trainer
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000 ，首次点击“播放”激活音频
必须走本地服务器（而非直接双击 index.html），否则浏览器的同源策略会阻止 fetch('./soundfonts/...sf2')。引擎与音色均已本地化，运行时无需联网。

八、已知限制

  • 主线程 ScriptProcessorNode 渲染（js-synthesizer 主线程版）在极低配设备可能有轻微卡顿；如需更低延迟可改 AudioWorklet 版（已随库附带 js-synthesizer.worklet.js）。
  • 免费版未实现“两音/音程”与“旋律听写”，见第六节扩展路径。
  • 统计按“音阶×标签”分区，切换标签时正确率表会切换对应数据集。
